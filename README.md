# ChronoNotes

[![Android CI](https://github.com/YOUR_USERNAME/ChronoNotes/actions/workflows/android.yml/badge.svg)](https://github.com/YOUR_USERNAME/ChronoNotes/actions/workflows/android.yml)

Аналог [EasyNotes](https://github.com/Kin69/EasyNotes) — приложение для заметок на **Kotlin + Jetpack Compose** (MVVM, Room, Material 3), переименованное и расширенное: календарь, напоминания и не только.

## Возможности

### Базовые
- Создание, редактирование и удаление заметок
- Markdown с предпросмотром (заголовки, списки, цитаты, код, ссылки)
- Шифрованный сейф
- Минималистичный Material 3 интерфейс, темы: системная / светлая / тёмная

### Дополнительные
| Фича | Описание |
| --- | --- |
| 📅 Календарь | Привязка заметок к датам, переход по месяцам, список событий дня. Цветные кружки тегов на каждом дне: **один кружок на уникальный тег**, даже если в этот день несколько заметок с ним |
| 🔔 Напоминания | Дата + время для любой заметки, системные уведомления через AlarmManager, восстановление после перезагрузки, список ближайших напоминаний в календаре |
| 🧩 Канбан-доска | Три колонки (Идеи / В работе / Готово), перенос карточек drag-and-drop с изменением порядка |
| 🕒 История версий | Автосохранение каждого изменения за 30 дней, просмотр и восстановление любой версии |
| ✅ Интерактивные чек-листы | Строки `- [ ]` превращаются в кликабельные чекбоксы прямо в предпросмотре |
| 🏷 Теги | Создание, цвета, фильтрация по нескольким тегам одновременно |
| 📌 Закрепление | Закреплённые заметки отдельной секцией и в виджете на главном экране |
| 🔐 Улучшенный сейф | AES-256-GCM, PBKDF2 (210 000 итераций), автоблокировка, смена пароля с перешифрованием, безопасный сброс |
| 🗑 Корзина | Восстановление и окончательное удаление |
| 📦 Импорт/экспорт | JSON-бэкап (даты и напоминания сохраняются) и экспорт в Markdown через системный выбор файла (SAF) |
| 🎨 Персонализация | Акцентный цвет, масштаб текста, адаптивная типографика |
| 🧱 Виджет | Закреплённые заметки на рабочем столе, открытие заметки по нажатию |

## Локальная сборка

Android Studio (Ladybug или новее) — просто откройте папку `ChronoNotes` и запустите `Build APK`.

Из командной строки (нужны JDK 17, Android SDK и установленный Gradle 8.7):

```bash
gradle assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`. Скрипт `gradlew` и `gradle-wrapper.jar` не включены — GitHub Actions и Android Studio создают wrapper автоматически.

Минимальная версия Android: **8.0 (API 26)**.

## Разрешения

- `POST_NOTIFICATIONS` (Android 13+) — для напоминаний, запрашивается при запуске
- `RECEIVE_BOOT_COMPLETED` — чтобы восстановить напоминания после перезагрузки
- `SCHEDULE_EXACT_ALARM` — для точных напоминаний (при отсутствии разрешения используется неточный будильник)

## Примечания

- В зашифрованных заметках шифруется **содержимое**; заголовок остаётся видимым (удобно для поиска и календаря).
- В уведомлении о напоминании для заметки из сейфа не попадает текст — только общий заголовок.
- При импорте JSON шифротекст переносится как есть — для чтения таких заметок нужен исходный пароль.
- История версий автоматически очищается за записи старше 30 дней.
- База данных имеет миграцию `1 → 2` (добавлены поля `noteDate` и `reminderAt`).
